# Drag'n Wash — 非官方本地化補丁 / 非官方本地化补丁 / 非公式ローカライズパッチ

## 繁體中文

本專案是 **Drag'n Wash 的非官方本地化補丁**，目前提供繁體中文、簡體中文及日文版本，翻譯遊戲中的對話、選項與介面文字。

目前為測試版，譯文由 AI 協助製作，仍在持續校對與修正。部分內容可能存在漏譯、語句不自然或排版問題。海報等圖片目前尚未完成本地化；各版本實際包含的內容請以 Releases 說明為準。本專案並非遊戲官方製作或背書。

### 安裝／升級

1. **關閉遊戲**，到本專案的 **Releases** 頁面下載所需語言的 ZIP 安裝包。請下載版本附件，不要下載 GitHub 自動產生的 `Source code (zip)`。
2. 如果曾安裝其他版本，先備份 `BepInEx/config/AutoTranslatorConfig.ini` 與 `BepInEx/Translation`。若曾使用舊版 `DragNWash.ZhTW` 外掛，請將整個外掛資料夾移到 `BepInEx` 以外；只覆蓋新檔案不會移除舊外掛。
3. 將 ZIP 內容解壓到 **`DragNWash.exe` 所在資料夾**，依需要覆蓋補丁相關檔案與設定。解壓後，`winhttp.dll`、`doorstop_config.ini`、`BepInEx` 應與遊戲執行檔位於同一層，請勿多套一層包名資料夾。
4. **一次選擇一種語言包。**切換語言時，請同時套用該語言包的設定檔，不要混放不同語言的翻譯文本。若已有其他模組，請先確認設定差異，避免影響原有模組。
5. 正常啟動遊戲，確認對話、選項與介面顯示正常。

請保留 **`DragNWash.XUnityLayoutFix.dll`**，它是對話翻譯所需的相容修正。舊的 `DragNWash.ZhTW` 不應重新啟用，圖片測試外掛 `DragNWash.TextureTest` 也不屬於正式安裝內容。

### 字型與相容性

- 目前以 Windows 64 位元 Mono 版、Unity `6000.3.14f1` 的遊戲環境製作，尚未保證適用所有遊戲版本。
- 繁體中文使用 **Microsoft JhengHei**，簡體中文使用 **Microsoft YaHei**，日文使用 **Yu Gothic**。若文字顯示方框或缺字，請確認 Windows 已安裝對應語言的補充字型，然後重新啟動遊戲。
- 翻譯由本機文本載入，不需要翻譯服務 API 金鑰。日文與簡體版仍需進一步校對及遊戲內顯示測試。

### 問題回報

若遊玩時發現 Bug、漏譯、語句不通順或排版問題，歡迎到 **Steam 討論區中的本補丁討論串**，或本專案的 **Issues** 頁面回報。

請盡量提供：使用語言、補丁與遊戲版本、發生問題的場景或操作步驟，以及原文或畫面截圖。若是閃退或載入問題，也請附上 `BepInEx/LogOutput.log`；公開前請檢查並遮蔽個人路徑等資訊。

### 移除與授權

關閉遊戲後，還原安裝前備份的設定，並移除本補丁的翻譯檔與專用外掛。若其他模組仍使用 BepInEx 或 XUnity，請保留共用元件。請勿刪除遊戲存檔。

本補丁使用 **BepInEx** 與 **XUnity AutoTranslator**。第三方元件授權請參閱安裝包內的 `Licenses`，相容修正原始碼位於 `Source`。重新散布時請保留相關授權聲明。遊戲名稱、原始文本及素材的權利屬於各自權利人。

## 日本語

本プロジェクトは、**Drag'n Wash の非公式ローカライズパッチ**です。繁体字中国語、簡体字中国語、日本語に対応し、ゲーム内の会話、選択肢、UI テキストを翻訳します。

現在はプレビュー版です。翻訳には AI を使用しており、引き続き校正と修正を行っています。未翻訳の箇所、不自然な表現、表示の崩れが残っている場合があります。ポスターなどの画像の翻訳は未完成です。各バージョンの収録内容は Releases の説明をご確認ください。本プロジェクトは、ゲーム開発元による公式制作・公認のパッチではありません。

### インストール／更新

1. **ゲームを終了**し、本プロジェクトの **Releases** ページから、使用する言語の ZIP ファイルをダウンロードしてください。GitHub が自動生成する `Source code (zip)` ではなく、リリースに添付されたパッチを選んでください。
2. 旧バージョンを導入済みの場合は、先に `BepInEx/config/AutoTranslatorConfig.ini` と `BepInEx/Translation` をバックアップしてください。旧プラグイン `DragNWash.ZhTW` がある場合は、そのフォルダー全体を `BepInEx` の外へ移動してください。新しいファイルを上書きするだけでは、旧プラグインは削除されません。
3. ZIP の内容を **`DragNWash.exe` と同じフォルダー**に展開し、必要に応じてパッチのファイルと設定を上書きしてください。`winhttp.dll`、`doorstop_config.ini`、`BepInEx` がゲームの実行ファイルと同じ階層になるようにし、パッチ名のフォルダーを余分に挟まないでください。
4. **使用する言語パックは一つだけ選んでください。**言語を切り替える際は、その言語パックの設定ファイルも適用してください。異なる言語の翻訳テキストを同じフォルダーに混在させないでください。他の MOD を導入している場合は、既存の設定への影響を確認してください。
5. 通常どおりゲームを起動し、会話、選択肢、UI が正しく表示されることを確認してください。

**`DragNWash.XUnityLayoutFix.dll` は削除しないでください。**会話の翻訳を正しく表示するために必要です。旧プラグイン `DragNWash.ZhTW` は再度有効にしないでください。画像テスト用の `DragNWash.TextureTest` も通常の配布内容には含まれません。

### フォントと互換性

- Windows 64 ビット Mono 版、Unity `6000.3.14f1` のゲーム環境を対象に作成しています。すべてのゲームバージョンでの動作を保証するものではありません。
- 繁体字中国語には **Microsoft JhengHei**、簡体字中国語には **Microsoft YaHei**、日本語には **Yu Gothic** を使用します。文字が四角になったり欠けたりする場合は、Windows の対応する言語の補助フォントをインストールし、ゲームを再起動してください。
- 翻訳はローカルのテキストファイルから読み込みます。翻訳サービスの API キーは不要です。日本語版と簡体字中国語版は、引き続き校正とゲーム内での表示確認が必要です。

### 不具合・翻訳の報告

不具合、未翻訳、不自然な表現、表示の崩れを見つけた場合は、**Steam コミュニティの本パッチのスレッド**、または本プロジェクトの **Issues** へご報告ください。

使用言語、パッチとゲームのバージョン、発生した場面や再現手順、原文またはスクリーンショットを添えていただけると助かります。クラッシュや読み込みの問題では、`BepInEx/LogOutput.log` も添付してください。公開前に、個人情報を含むパスなどがないか確認し、必要に応じて伏せてください。
